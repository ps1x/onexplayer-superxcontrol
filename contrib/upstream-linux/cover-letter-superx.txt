Subject: [PATCH v3] platform/x86: oxpec: add support for OneXPlayer Super X

Hi,

this v3 adds DMI-based support for OneXPlayer Super X to
drivers/platform/x86/oxpec.c.

The tested Super X system exposes DMI strings as `ONE-NETBOOK` /
`ONEXPLAYER SUPER X`, but current mainline `oxpec` does not match those
strings, so the in-tree driver is not auto-loaded.

Compared to v2, this version reuses the existing `oxp_g1_a` board data
instead of adding a dedicated `oxp_superx` board id. Local hardware testing
showed that the Super X fan, PWM, turbo-toggle, and battery charge-control EC
layout matches the existing ONEXPLAYER G1 A handling.
